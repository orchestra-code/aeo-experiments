# 009: Can cheaper Claude API calls stand in for a claude.ai subscriber? (design sketch)

**Status:** sketch, NOT a spec, nothing frozen. The harness is built and
smoke-tested; `spec.md` follows the pilot.

## The question

Tracking Claude at scale means calling the API. The cheapest believable call
(Sonnet 5 or Haiku 4.5) costs a fraction of the frontier model a claude.ai
subscriber gets by default (Opus 5.5 since 2026-09-22). Hypothesis: for B2B
product and solution research, a cheaper API call returns the same brands and
cites the same sources as a subscriber on the default model, close enough to
stand in for it. Side questions: what reasoning changes, and whether an API
call on the SAME model (plain, or with the leaked claude.ai system prompt)
matches the subscription.

## Arms (same prompts, same day, 3 waves on non-consecutive days)

| Arm | Surface | Model / reasoning | System prompt |
|---|---|---|---|
| `ui_default` | claude.ai, collected by hand | Opus 5.5, Medium reasoning (picker default) | claude.ai's own |
| `ui_think` | claude.ai, collected by hand | Opus 5.5, High reasoning | claude.ai's own |
| `opus55_leak` | API | `claude-opus-5-5`, effort medium | leaked 5.5 prompt, trimmed |
| `opus55_plain` | API | `claude-opus-5-5`, effort medium | none |
| `sonnet5_leak_think` | API | `claude-sonnet-5`, adaptive thinking | leaked, trimmed |
| `sonnet5_leak_nothink` | API | `claude-sonnet-5`, thinking disabled | leaked, trimmed |
| `sonnet5_prod` | API | the production request, byte for byte | Spyglasses discovery prompt |
| `haiku45_leak` | API | `claude-haiku-4-5`, no thinking | leaked, trimmed |

The claude.ai picker's default reasoning label for Opus 5.5 is **Medium**
(observed 2026-09-26 on a fresh Pro account), which matches the API arms'
`output_config.effort: "medium"`. The wording of the higher setting is
confirmed from the pilot notes.

Pilot-only API arms (never part of `--arms all`): `sonnet5_leak_low` (Sonnet 5,
adaptive thinking at effort low; a candidate replacement for
`sonnet5_leak_nothink`, which did not search in the smoke test),
`opus55_leak_fetch` (adds `web_fetch_20260209`, max 5 fetches, 10k content
tokens), `opus55_leak_ws2026` (`web_search_20260209`) and `opus55_leak_raw`
(the untrimmed leak, 5 prompts).

Research API arms: `web_search_20250305` (max 10 uses, the collector's
approximate location), `max_tokens` 16000, no temperature, no refusal
fallbacks. Full waves go through the Batches API with the leaked prompt cached
for 1 hour. Harness: `harness/arms.py`, `harness/collect_anthropic.py`.

## Prompts

40 synthetic B2B prompts, 20 software categories x 2 intents (a shortlist for
a stated company profile; evaluate and compare options for a use case),
generated by `harness/make_prompts.py`, rule-checked (no brands, no location,
15 to 45 words), reviewed by a person and frozen before the pilot. Categories
only, never brands, so no customer brand appears; the text is releasable under
the synthetic-study exemption in `docs/data-policy.md`.

## Measures (drafted; the spec freezes them)

- Overlap: top-10 brand-set Jaccard (RBO alongside) and cited registered-domain
  Jaccard, against the within-arm noise floor across waves.
- H1 (primary): each cheap arm's gap to `ui_default`, TOST with the house 0.10
  band, for brands and domains; panel brand-share MAD under 0.05. Holm across
  the family. H1-ref: `opus55_leak` against the UI (the ceiling).
- H2 (reasoning): think vs no-think on Sonnet 5, and `ui_default` vs `ui_think`.
- H3 (API vs subscription, same model): the `opus55_plain` and `opus55_leak`
  gaps to the UI, framed as instrument divergence.
- Descriptive: searches per answer, source mix, answer length, measured
  dollars per call per arm.

## Framing constraints

- This measures **instrument divergence**, never "the effect of THE system
  prompt". The leak's provenance cannot be verified, and the API's
  `web_search` is not claude.ai's retrieval stack (claude.ai also has
  `web_search_fast` and `web_fetch`).
- The UI arms are one account with personalization switched off. Logged-in
  personalization is out of scope and the write-up says so.
- Search behavior is itself an instrument effect: Sonnet 5 with thinking
  disabled and the leaked prompt answered without searching on 3 of 3 smoke
  prompts, and searched on 7 of 10 pilot prompts.

## Search location

The UI account signs in from Pittsburgh, so every confirmatory API wave uses
`user_location` Pittsburgh, Pennsylvania, US (the collector's default). The
smoke test and the pilot's API calls used Boston, Massachusetts, US; that is a
recorded pilot deviation that applies to any pilot number affected by location.

## Pilot findings (2026-09-26; aggregates only, full tables in results/pilot_report.md)

- **claude.ai export format confirmed.** The export holds the search query
  (`tool_use` named `web_search`, `input.query`), the results (`tool_result`
  items of type `knowledge` with a `url`) and text citations
  (`citations[].details.url`). The parser matched 10 of 10 pilot chats.
- **UI reasoning default is Medium** for Opus 5.5, matching the API arms'
  `effort: "medium"`.
- **`web_search_20260209` is ruled out.** On `opus55_leak` it ran 8.2
  searches per answer but returned zero inline citations and zero links on
  all 10 prompts, so cited-domain overlap cannot be measured with it.
- **`sonnet5_leak_nothink` searched on 7 of 10 pilot prompts** (0 of 3 in the
  smoke test). `sonnet5_leak_low` searched on 8 of 10.
- **web_fetch unused:** `opus55_leak_fetch` made 0 fetches across 10 prompts.
- **The UI profile is closest to the plain API call:** 1.8 searches, 7.1 cited
  and 16.4 evaluated URLs per answer, against 1.8, 8.6 and 16.3 for
  `opus55_plain`; `opus55_leak` searched about twice as often (3.8).
- **Answers name brands in prose**, not in bold or headings, so brand
  extraction needs a model pass plus a curated lexicon. The pilot's Haiku pass
  still picks up some out-of-category brands (integration targets); the
  lexicon curation step handles that before the freeze.

## Open questions for the pilot

1. Does the claude.ai export include search results and citations? If not,
   pick a fallback capture before any wave. (Answered: yes, see above.)
2. Does the trimmed leak make any model write tool calls as text (compared with
   the full leak on 5 prompts)?
3. What reasoning control does the picker offer for Opus 5.5? (Default is
   Medium; confirm the name of the higher setting.)
4. How often does `sonnet5_leak_nothink` search at all? If almost never, keep
   it as a measured behavior or add a search nudge (that choice changes the
   arm, so it is made before the freeze).
5. Batch cache-hit behavior and measured dollars per call per arm.
